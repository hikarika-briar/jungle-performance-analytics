# Jungle Performance Analytics · Hikarika#BRIAR

Painel público de desempenho de jungle no League of Legends, publicado em
https://hikarika.marcelominerato.com.br

- `index.html`: o painel (versão só de leitura).
- `dados/jungle_data.json`: partidas, gerado pelo coletor.
- `dados/referencias_challenger.json`: partidas dos jogadores Challenger de referência.
- `dados/preferencias.json`: metas, elo marcado mês a mês e enquadramento do fundo.
- `dados/fundo.webp`: imagem de fundo do banner.
- `preview.jpg`: imagem de prévia ao compartilhar o link.
- `CNAME`: endereço do site no GitHub Pages.

Para atualizar os dados, troque os arquivos da pasta `dados/`.
